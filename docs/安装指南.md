# pygeomodels 环境配置指南

## 1. 创建Conda环境

```bash
# 创建名为pygeomodels的新环境，指定Python版本为3.11
conda create -n pygeomodels python=3.11 -y

# 激活环境
conda activate pygeomodels
```

## 2. 升级pip

```bash
pip install --upgrade pip
```

## 3. 安装核心依赖

```bash
# 安装项目运行所需的依赖
pip install -r requirement.txt
```

## 4. 安装项目本身

```bash
# 进入项目目录
cd /Users/wuchenglong/Desktop/EGC/pygeomodels

# 以开发模式安装（便于开发时修改代码）
pip install -e .
```

## 5. 验证安装

```bash
# 验证核心包
python -c "import pygeomodels; print('pygeomodels imported successfully')"

# 验证MCP服务框架
python -c "from fastmcp import FastMCP; print('FastMCP imported successfully')"

# 验证数据科学库
python -c "import xarray, matplotlib, rasterio, geopandas, pygeoc; print('All libraries imported successfully')"
```

## 6. 配置文件

确保项目目录下存在 `default_config.ini` 配置文件，配置服务URL和认证信息。参考 `config.py` 中的配置格式。

## 7. 使用说明

### 运行MCP服务
```bash
conda activate pygeomodels
python pygeomodels_service.py
```

### 使用Jupyter Notebook
```bash
conda activate pygeomodels
jupyter notebook
# 打开 Quickstart.ipynb 开始使用
```

### 运行测试
```bash
conda activate pygeomodels
pytest
```
